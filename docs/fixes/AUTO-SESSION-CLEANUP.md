# Автоматическая очистка невалидных сессий

## Проблема

При попытке подключения бота, если сохраненная сессия невалидна (например, бот был отключен на телефоне), WhatsApp возвращает ошибку 401 (Unauthorized). Это приводило к тому, что:

1. QR код не генерировался
2. Бот не мог переподключиться
3. Пользователь видел таймаут при попытке получить QR код

## Решение

Добавлена автоматическая очистка невалидных сессий при получении ошибки авторизации:

### Изменения в `src/services/worker-baileys.manager.ts`

1. **Добавлен импорт `fs/promises`** для работы с файловой системой

2. **Добавлен метод `deleteSession()`**:
   - Удаляет директорию с сессией бота из файловой системы
   - Вызывается автоматически при обнаружении ошибки авторизации

3. **Обновлена логика обработки отключения**:
   - Определяется, является ли ошибка ошибкой авторизации (statusCode === 401 или DisconnectReason.loggedOut)
   - При ошибке авторизации автоматически удаляется невалидная сессия
   - Бот не пытается переподключиться с невалидной сессией
   - При следующей попытке подключения будет создана новая сессия и сгенерирован свежий QR код

## Результат

Теперь при получении ошибки 401:
1. Старая невалидная сессия автоматически удаляется
2. В логах появляется сообщение: `"Bot {botId} has invalid session (status 401), deleting session"`
3. При следующей попытке подключения бот создаст новую сессию
4. QR код будет успешно сгенерирован для сканирования

## Тестирование

Для проверки исправления:
1. Создайте бота и подключите его
2. Отключите бота на телефоне (выйдите из WhatsApp Web)
3. Попробуйте переподключить бота через интерфейс
4. Убедитесь, что QR код генерируется успешно

## Логи

При удалении невалидной сессии в логах будут следующие сообщения:

```json
{
  "level": "warn",
  "message": "Bot {botId} has invalid session (status 401), deleting session"
}
{
  "level": "info",
  "message": "Deleting invalid session for bot {botId} at /app/sessions/{botId}"
}
{
  "level": "info",
  "message": "Session deleted successfully for bot {botId}"
}
{
  "level": "info",
  "message": "Invalid session deleted for bot {botId}, ready for fresh QR code generation"
}
```
