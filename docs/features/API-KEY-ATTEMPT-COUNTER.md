# Счетчик попыток ввода пароля для просмотра API ключа

## Описание

Добавлен визуальный счетчик попыток ввода пароля при попытке просмотра API ключа. Это повышает безопасность и информирует пользователя о количестве оставшихся попыток.

## Функциональность

### Счетчик попыток
- **Начальное значение**: 5 попыток
- **Визуальный индикатор**: Отображается в правом верхнем углу модального окна в формате "X / 5"
- **Цветовая индикация**:
  - 5-4 попытки: серый фон (нормальное состояние)
  - 3 попытки: желтый фон (предупреждение)
  - 2-1 попытки: красный фон (критическое состояние)
  - 0 попыток: блокировка

### Поведение

1. **При неправильном пароле**:
   - Счетчик уменьшается на 1
   - Отображается сообщение об ошибке с указанием оставшихся попыток
   - Пример: "Invalid password. 4 attempts remaining."

2. **При достижении 0 попыток**:
   - Кнопка "Show API Key" блокируется и меняет текст на "Locked"
   - Отображается сообщение: "Too many failed attempts. Please try again later."
   - Поле ввода пароля остается доступным для просмотра

3. **При успешном вводе пароля**:
   - Счетчик сбрасывается до 5
   - Отображается API ключ

4. **При закрытии модального окна**:
   - Счетчик сбрасывается до 5
   - Блокировка снимается
   - Все состояния очищаются

## Изменения в коде

### Frontend: `frontend/src/components/bots/ApiKeyModal.tsx`

#### Добавленные состояния:
```typescript
const [attemptsLeft, setAttemptsLeft] = useState<number>(5)
const [isLocked, setIsLocked] = useState(false)
```

#### Обновленная логика обработки ошибок:
```typescript
// Check if it's an authentication error
if (err?.response?.status === 401 || errorMessage.toLowerCase().includes('password')) {
  const newAttemptsLeft = attemptsLeft - 1
  setAttemptsLeft(newAttemptsLeft)
  
  if (newAttemptsLeft <= 0) {
    setIsLocked(true)
    setError('Too many failed attempts. Please try again later.')
  } else {
    setError(`${errorMessage}. ${newAttemptsLeft} attempt${newAttemptsLeft !== 1 ? 's' : ''} remaining.`)
  }
}
```

#### Визуальный индикатор:
```tsx
<div className={`text-sm font-medium px-3 py-1 rounded-full ${
  attemptsLeft <= 2 
    ? 'bg-red-100 text-red-700' 
    : attemptsLeft <= 3 
    ? 'bg-amber-100 text-amber-700' 
    : 'bg-gray-100 text-gray-700'
}`}>
  {attemptsLeft} / 5
</div>
```

## UI/UX

### Визуальные состояния

1. **Нормальное состояние (5-4 попытки)**:
   - Серый бейдж с текстом "5 / 5" или "4 / 5"
   - Кнопка активна

2. **Предупреждение (3 попытки)**:
   - Желтый бейдж с текстом "3 / 5"
   - Кнопка активна
   - Сообщение об ошибке с количеством попыток

3. **Критическое состояние (2-1 попытки)**:
   - Красный бейдж с текстом "2 / 5" или "1 / 5"
   - Кнопка активна
   - Сообщение об ошибке с количеством попыток

4. **Блокировка (0 попыток)**:
   - Красный бейдж с текстом "0 / 5"
   - Кнопка заблокирована с текстом "Locked"
   - Сообщение: "Too many failed attempts. Please try again later."

## Безопасность

### Текущая реализация (Frontend)
- Счетчик попыток хранится в состоянии компонента
- Сбрасывается при закрытии модального окна
- Блокировка действует только в рамках текущей сессии модального окна

### Рекомендации для будущих улучшений
1. **Backend rate limiting**: Добавить ограничение на стороне сервера
2. **Временная блокировка**: Блокировать попытки на определенное время (например, 5 минут)
3. **Логирование**: Записывать неудачные попытки в логи для мониторинга
4. **Уведомления**: Отправлять уведомления пользователю о подозрительной активности

## Тестирование

### Сценарии тестирования:

1. **Успешный ввод пароля**:
   - Открыть модальное окно
   - Ввести правильный пароль
   - Убедиться, что API ключ отображается
   - Счетчик должен сброситься до 5

2. **Неправильный пароль (1-4 попытки)**:
   - Открыть модальное окно
   - Ввести неправильный пароль
   - Убедиться, что счетчик уменьшился
   - Проверить цвет бейджа
   - Проверить сообщение об ошибке

3. **Исчерпание попыток**:
   - Открыть модальное окно
   - Ввести неправильный пароль 5 раз
   - Убедиться, что кнопка заблокирована
   - Проверить сообщение об ошибке

4. **Сброс после закрытия**:
   - Исчерпать попытки
   - Закрыть модальное окно
   - Открыть снова
   - Убедиться, что счетчик сброшен до 5
