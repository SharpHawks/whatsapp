# Requirements Document

## Introduction

Расширение функциональности отправки сообщений для поддержки отправки как в личные чаты (по номеру телефона), так и в группы WhatsApp. Добавление возможности просмотра списка групп и их идентификаторов, а также документации API для отправки сообщений.

## Glossary

- **System**: WhatsApp API Platform - веб-приложение для управления WhatsApp ботами
- **User**: Пользователь системы, который отправляет сообщения
- **Bot**: WhatsApp бот, подключенный к системе
- **Group**: Группа WhatsApp, в которой участвует бот
- **Group ID**: Уникальный идентификатор группы WhatsApp (формат: `123456789@g.us`)
- **Phone Number**: Номер телефона получателя (формат: `+1234567890`)
- **Tab**: Вкладка в интерфейсе для переключения между режимами отправки

## Requirements

### Requirement 1: Переключение между режимами отправки

**User Story:** Как пользователь, я хочу выбирать между отправкой сообщения в личный чат или в группу, чтобы иметь гибкость в выборе получателя.

#### Acceptance Criteria

1. WHEN User открывает страницу Send Message, THE System SHALL отображать две вкладки: "Send to Contact" и "Send to Group"
2. WHEN User кликает на вкладку, THE System SHALL переключать контент формы в соответствии с выбранным режимом
3. THE System SHALL сохранять выбранную вкладку при навигации внутри страницы
4. THE System SHALL отображать активную вкладку с визуальным индикатором

### Requirement 2: Отправка сообщения в личный чат

**User Story:** Как пользователь, я хочу отправлять сообщения по номеру телефона, чтобы связываться с конкретными контактами.

#### Acceptance Criteria

1. WHEN User выбирает вкладку "Send to Contact", THE System SHALL отображать поле ввода для номера телефона
2. THE System SHALL валидировать формат номера телефона перед отправкой
3. WHEN User вводит корректный номер и отправляет сообщение, THE System SHALL отправить сообщение через выбранного бота
4. THE System SHALL отображать статус отправки сообщения

### Requirement 3: Загрузка списка групп

**User Story:** Как пользователь, я хочу видеть список групп, в которых участвует мой бот, чтобы выбрать нужную группу для отправки сообщения.

#### Acceptance Criteria

1. WHEN User выбирает вкладку "Send to Group", THE System SHALL загрузить список групп для выбранного бота
2. THE System SHALL отображать название группы и её идентификатор для каждой группы
3. WHEN список групп пуст, THE System SHALL отображать сообщение "No groups found"
4. THE System SHALL обновлять список групп при смене выбранного бота

### Requirement 4: Отправка сообщения в группу

**User Story:** Как пользователь, я хочу отправлять сообщения в группы WhatsApp, чтобы общаться с несколькими участниками одновременно.

#### Acceptance Criteria

1. WHEN User выбирает группу из списка, THE System SHALL заполнить поле получателя идентификатором группы
2. THE System SHALL отправить сообщение в выбранную группу при нажатии кнопки отправки
3. THE System SHALL отображать статус отправки сообщения в группу
4. THE System SHALL валидировать, что группа выбрана перед отправкой

### Requirement 5: API документация

**User Story:** Как разработчик, я хочу видеть документацию API для отправки сообщений, чтобы интегрировать функциональность в свои приложения.

#### Acceptance Criteria

1. THE System SHALL отображать секцию "API Documentation" под формой отправки сообщений
2. THE System SHALL показывать примеры curl запросов для отправки в личный чат
3. THE System SHALL показывать примеры curl запросов для отправки в группу
4. THE System SHALL отображать описание параметров запроса
5. THE System SHALL показывать примеры ответов API

### Requirement 6: Backend API для получения групп

**User Story:** Как система, я должна предоставлять API для получения списка групп бота, чтобы frontend мог отображать их пользователю.

#### Acceptance Criteria

1. THE System SHALL предоставлять endpoint `GET /api/v1/bots/:botId/groups`
2. WHEN запрос выполнен с валидным botId, THE System SHALL вернуть список групп с их идентификаторами и названиями
3. THE System SHALL требовать JWT аутентификацию для доступа к endpoint
4. THE System SHALL проверять, что пользователь является владельцем бота
5. WHEN бот не подключен, THE System SHALL вернуть ошибку с кодом 400

### Requirement 7: Хранение информации о группах

**User Story:** Как система, я должна хранить информацию о группах, в которых участвует бот, чтобы предоставлять актуальные данные пользователю.

#### Acceptance Criteria

1. WHEN бот подключается к WhatsApp, THE System SHALL получить список групп от WhatsApp API
2. THE System SHALL сохранять информацию о группах в памяти или кэше
3. THE System SHALL обновлять список групп при изменениях (добавление/удаление бота из группы)
4. THE System SHALL предоставлять актуальную информацию о группах через API
